# Garden of Avalon — Editorial proposal

An independent visual proposal for the Garden of Avalon photo archive.

## What is different here?

- An editorial landing page rather than a conventional photo grid.
- A curated selection of 16 photographs instead of displaying the entire archive immediately.
- Four collections: city traces, botanical interruptions, painted walls, and rooms of light.
- A keyboard-friendly, looped photo viewer: use the left and right arrows, or the on-screen controls.

## View locally

Open `index.html` with any browser, or serve the folder with a local web server.
